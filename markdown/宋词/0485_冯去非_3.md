# 冯去非

--(1192－1272 以后) 字可迁，号深居，南康都昌 (今属江西) 人。淳元年 (1241) 进士。曾任淮南东路转运使司干办公事，召为宗学谕，以忤丁大全罢归庐山。存词三首。

## 八声甘州

买扁舟、载月过长桥，回首梦耶非。

问往日三高，清风万古，继者伊谁。

惟有茶烟轻扬，零露湿莼丝。

西子知何处，鸿怨蛩悲。

遥想家山好在，正倚天青壁，石瘦云肥。

甚抛奇亸秀，猿鹤互猜疑。

归去好、散人相国，迥升沈、毕竟总尘泥。

须还我，松间旧隐，竹上新诗。

## 点绛唇

秋满孤篷，翠蒲红蓼留人住。

一帘香缕。

边影惊鸿度。

小据胡床，旧事新情绪。

凭谁诉。

蜡灯犀尘。

拟共西风语。

## 喜迁莺

凉生遥渚。

正绿芰擎霜，黄花招雨。

雁外渔村，蛩边蟹舍，绛叶满秋来路。

世事不离双鬓，远梦偏欺孤旅。

送望眼，但凭舷微笑，书空无语。

慵觑。

清镜里，十载征尘，长把朱颜污。

借箸青油，挥毫紫塞，旧事不堪重举。

间阔故山猿鹤，冷落同盟鸥鹭。

倦游也，便樯云柁月，浩歌归去。
