# 张少博

张少博，大历进士。诗二首。

## 尚书郎上直闻春漏

建礼含香处，重城待漏辰。

徐声传凤阙，晓唱辨鸡人。

银箭听将尽，铜壶滴更新。

催筹当五夜，移刻及三春。

杳杳从天远，泠泠出禁频。

直庐残响曙，肃穆对钩陈。

## 雪夜观象阙待漏

残雪初睛后，鸣珂奉阙庭。

九门传晓漏，五夜候晨扃。

北斗横斜汉，东方落曙星。

烟氛初动色，簪佩未分形。

雪重犹垂白，山遥不辨青。

鸡人更唱处，偏入此时听。
