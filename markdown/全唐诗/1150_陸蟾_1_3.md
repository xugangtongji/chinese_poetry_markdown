# 陸蟾

蟾，寓居潭州攸縣司空山。好神仙事，多辟穀累月。雍熙中服藥卒。

## 司空山聞子規

後夜入清明，遊人何處聽？

花殘斑竹廟，雨歇峴山亭。

樹罅月欲落，窗間酒正醒。

衆鳥方在夢，誰念爾勞形？

（《詩話總龜》十一引《雅言系述》）。

## 春暮經石頭城

六朝多少事，搘肘思悠悠。

落日空江上，子規啼渡頭。

蒹葭侵[壞]（廢）壘，烟霧接滄洲。

今古分明在，那堪向九秋？

（以上《詩話總龜》十五引《雅言雜載》）（〖1〗北宋釋契嵩《鐔津文集》卷十三有《陸蟾傳》，云蟾爲藤州鐔津人，有王霸大略，以能詩名於楚越間，後客死於攸縣司空山。

又引高閬語稱爲國初人。

〖2〗《陸蟾傳》所引，題作《瀑布詠》，「正源」作「靈源」，「浴」作「凝」，「射」作）（「濺」，「流」作「待」，「翻」作「爲」。

）。

## 題廬山瀑布

正源人莫測，千尺掛雲端。

岳色染不得，神功裁亦難。

夏噴猿鳥浴，秋射斗牛寒。

流到滄溟日，翻濤更好看。

〖2〗。
