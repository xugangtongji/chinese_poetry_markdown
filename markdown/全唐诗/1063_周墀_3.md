# 周墀

周墀，字德升，汝南人。擢进士第，辟湖南巡官，入为监察御史、集贤殿学士。李宗闵镇山南，表行军司马，阅岁召还，以考功员外郎兼起居舍人事知制诰。武宗即位，改工部侍郎，出为义成节度使，寻以兵部侍郎召判度支，进同中书门下平章事，俄罢为劒南西川节度使。诗二首。

## 贺王仆射放榜

文场三化鲁儒生，三十余年振重名。

曾忝木鸡夸羽翼，又陪金马入蓬瀛。

虽欣月桂居先折，更羡春兰最后荣。

欲到龙门看风雨，关防不许暂离营。

## 酬李常侍立秋日奉诏祭岳见寄

秋祠灵岳奉尊罍，风过深林古柏开。

莲掌月高珪币列，金天雨露鬼神陪。

质明三献虽终礼，祈寿千年别上杯。

岂是琐才能祀事，洪农太守主张来。
