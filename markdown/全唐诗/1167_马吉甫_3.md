# 马吉甫

《唐会要》卷三十六记预修《三教珠英》的二十六人中有马吉甫。吉甫事迹无攷，《珠英集》题：「太子文学扶风马吉甫。」（《元和姓纂》卷七诸郡马氏有吉甫，正平人。岑仲勉《四校记》考定吉甫圣历元年直崇文馆，大足元年与修《三教珠英》，长安四年作《蜗牛赋》，又曾任修文学士、中书舍人。）

## 秋晴过李三山池（斯二七一七下同）

山游[□]未狎，朝隐遂为群。

地僻烟霞异，心闲出处分。

褰开弄晴景，披拂喜朝闻，（「闻」，蒋当作「雰」。

）野兴浮黄菊，林栖卧白云。

窥临苔壁古，歌啸竹亭曛。

回想幽岩路。

知予复解纷。

## 秋夜怀友

故人在天末，空庭明月时。

白云劳悟（寤）寐，芳树歇华滋。

蟋蟀鸣秋草，蜘蛛弄晓丝。

菊花应可泛，留兴待□□。
