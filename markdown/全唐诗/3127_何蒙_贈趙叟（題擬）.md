# 何蒙

何蒙，南唐進士。詩一首。（《全唐詩》無何蒙詩）（俁蒙，《宋史》卷二七七有傳，字叔昭，洪州人。南唐後主時，獻書言事得官。入宋授洺州推官。太平興國五年，調遂寧令，作詩獻太宗，授右贊善大夫。後歷知梧、鄂、太平、袁、濠等州，大中祥符六年卒，年七十七。其獻宋太宗詩，《全唐詩》卷七六八收入，但作者姓名誤作「何象」。）

## 贈趙叟（題擬）

桂枝輪卻正淒然，又被鸎聲聒晝眠。

唯有趙翁知仔細，相傳好語待來年。

（見《江南餘載》卷上。

）（〖1〗《江南餘載》：趙叟者，自保大之初至於開寶之季，嘗爲貢院門子，每歲放榜之後，或去或留，率慶慰之，若出於叟手然。

進士何蒙目前叟詩曰〖詩不重錄〗云云。

）。
