# 李靖

靖，本名藥師，雍州三原人。少有文武材略。初仕隋，爲長安縣功曹、駕部員外郎、馬邑郡丞。唐高祖時，任行軍總管，從李孝恭征蕭銑，復度嶺招撫嶺南諸州，屢立軍功。太宗時，歷任刑部尚書、兵部尚書、尚書右僕射等職，先後擊敗東突厥、吐谷渾。初封代國公，改衛國公。貞觀二十三年卒，年七十九。詩一首。（《全唐詩》無李靖詩。事跡據《舊唐書》卷六七本傳。）
