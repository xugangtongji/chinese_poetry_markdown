# 任宇

任宇，生平無考。詩一首。（任宇，《元和姓籔》卷五云爲渭州人，任迪簡之次子。兩《唐書》有《任迪簡傳》，作京兆萬年人。張忱石《〈全唐詩〉無世次作者事迹考索》云渭州當作渭南，任氏自漢任敖之後徙居渭南，唐初任雅相遷至萬年。當以後者更爲準確。《新安志》卷九云任宇於咸通七年任歙州刺史，此詩即作於其時。《郎官石柱題名》戶部員外郎有任宇，名列裴虔餘後，薛調前，亦咸通間任。原列「無考」作者，今移此。）（《全唐詩》無任宇詩）
