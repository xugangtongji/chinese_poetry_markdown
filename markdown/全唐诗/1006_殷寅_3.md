# 殷寅

殷寅，陳郡人。早孤，事母以孝聞。應宏詞舉，爲永寧尉，與蕭頴士善。詩二首。

## 銓試後徴山別業寄源侍御

別業在徴山，登高望畿甸。

嚴令天地肅，城闕如何見。

藹藹王侯門，華軒日遊衒。

幸逢休明代，山虜尚交戰。

投策去園林，率名皆拜選。

聖君性則哲，濟濟多英彥。

裴楷能清通，山濤急推薦。

謏才甘自屏，薄伎忝餘眷。

雖承國士恩，尚乏中人援。

疇昔相知者，今茲秉天憲。

朱紱何赫赫，繡衣復蔥蒨。

## 玄元皇帝應角賀聖祚無疆

應曆生周日，脩祠表漢年。

復茲秦嶺上，更似霍山前。

昔贊神功啓，今符聖祚延。

已題金簡字，仍訪玉堂仙。

睿祖光元始，曾孫體又玄。

言因六夢接，慶叶九齡傳。

北闕心超矣，南山壽固然。

無由同拜慶，竊抃賀陶甄。
