# 王潛

王潛字弘志，相州安陽人，爲駙馬都尉光禄卿王同皎孫。元和中擢將作監，遷左散騎常侍，拜涇原節度使。穆宗即位，封琅琊郡公。大和初，檢校尚書左僕射，卒於官。（《新唐書》卷一百九十一有傳附於《王同皎傳》。）詩一首。（《全唐詩》無王潛詩。）（本詩作者王潛建中二年已官「節度都巡使太常卿上柱國」，其子王同皎孫王潛，恐非一人。）

## 題雲居上寺

萬木千峯空鳥喧，潺潺[溪]水下長川。

人來石室藏何處。

一逕歸時帶暮煙。

（見《金石萃編》卷一百五。

）（〖1〗石刻詩次吉潛詩後。

下署「節度都巡使太常卿上柱國王潛」。

第二句第三字原作「氵」，摩其右半，意者或爲「澗」字，或爲「流」字，雖然，未敢擅補也。
