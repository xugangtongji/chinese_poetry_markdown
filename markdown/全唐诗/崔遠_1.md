# 崔遠

遠，博陵安平人，吏部侍郎澹子。龍紀元年登進士第。大順初，以員外郎知制誥，召充翰林學士，正拜中書舍人。乾寧三年，轉戶部侍郎、兵部侍郎承旨，尋以本官同平章事，遷中書侍郎兼吏部尚書。天祐初，從昭宗東遷洛陽，罷相，守右僕射。二年，爲柳璨希朱全忠意，累貶白州長史，旋被害。遠文才清麗，風神峻整，爲時所重。詩一首。（《全唐詩》無崔遠詩，事跡據《舊唐書》卷一七七《崔珙傳》附本傳）

## 送廣利大師歸江東

楚山楓老楚江清，笠挂高帆浪注罌。

真性本無前後際，葉舟誰問去來程。

忘機每與鷗爲伴，息念應憐月共明。

想見家山諸弟子，盛誇新賜大師名。

（見宋岳珂纂《寶真齋法書贊》卷六）（按：岳珂云此詩真跡一卷，嘉定甲申九月贖之邵邸，楷書，詩幷序尾紀共八行。

詩末署：「中書侍郎平章事崔遠，乾寧四年季夏二十九日書。

」珂另有贊語，評其書法，茲不錄。
