# 宋维

维，武进人，举进士，官员外郎，与李中同时。诗三首。（《全唐诗》无宋维诗。李中《碧云集》卷三有《暮春有感寄宋维员外》、《杪秋夕吟怀寄宋维先辈》、《春日招宋维先辈》诸诗。）

## 题天申宫三首 一

殿阙（《宜兴县志》作「阁」）盘空压巨鳌，洗然灵迹助风骚。

玉龙卧久洞云冷，玄鹤唳频山月高。

深谷羽童探石菌，晓堂真侣饮樱（《宜兴县志》作「仙」）桃。

可怜不悟长生者，尘里区区改鬓毛。

## 题天申宫三首 二

中峰嘉树绿阴阴，洞里灵踪已遍寻。

欲下山门又回首，数声清磬白云深。

## 题天申宫三首 三

云岚满袖倚嵓扉，龙窟寒生夜睡迟。

一曲朱弦谁与听，月斜风撼碧桃枝。

（见洪武刻本《咸淳毘陵志》卷二十二，嘉庆二年刊宁楷等纂《宜兴县志》卷十收第一首。

）（按：《四库全书》本《江南通志》卷一一九录宋干德进士有宋维。

疑维初居江南，后北上应试。

《毘陵志》归南唐，今从之。

）。
