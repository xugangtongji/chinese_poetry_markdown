# 智藏

智藏，日本僧人，俗姓禾田氏。淡海帝世，遣學唐國，就吳越高學尼受業。六七年中，學業穎秀。同伴忌害之，遂被髮陽狂，密寫三藏要義，盛以木筒，負擔遊行，同伴視爲鬼狂，遂不爲害。太后天皇世歸日本，昇座敷演，辭義峻遠，帝嘉之，拜僧正，時年七十三。詩二首。（《全唐詩》無智藏詩，傳節錄《懷風藻》本傳）

## 五言秋日言志一首

欲知得性所，來尋仁智情。

氣爽山川麗，風高物候芳。

燕巢辭夏色，鴈渚聽秋聲。

因茲竹林友，榮辱莫相驚。

（均見《日本古典文學大系》六九冊《懷風藻》）（按：《懷風藻》目錄稱「僧正吳學生智藏師」智藏在唐居住時間甚久，至暮年始返國。

二詩作年不可考，疑即在唐日作。

）。

## 五言翫花鶯一首

桑門寡言晤，策杖事迎逢。

以此芳春節，忽值竹林風。

求友鶯嫣（一作「嬌」）樹，含香花笑叢。

雖喜遨遊志，還媿乏雕蟲。

。
