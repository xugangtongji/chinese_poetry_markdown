# 高士廉

士廉，渤海蓨人。隋大業中，爲治禮郎，貶朱鳶主簿。入唐，累遷雍州治中。貞觀初，拜侍中，封義興郡公，進許國公，官至尚書右僕射。二十一年卒，年七十二。詩一首。（《全唐詩》無高士廉詩，傳據《舊唐書》卷六五本傳）

## 五言春日侍宴次望海應詔

玉律應青陽，鸞駕幸春方。

篲雲陳罕罼，亘野列旗常。

雕弓連月彩，雄劍聚星光。

觀兵遼碣上，停驂渤澥傍。

浮天既淼淼，浴日復滄滄。

水映紅桃色，風飄丹𪱳（疑爲「桂」字）香。

蜃結疑樓峙，濤驚似蓋張。

三韓沐醇化，四郡竚唯良。

深仁苞動植，神武讋遐荒。

願草登封禮，簪紱奉周行。

（《翰林學士集》）（按：此詩原署「開府儀同三司申國公臣高士廉上」。

張步雲《唐代逸詩輯存》收入。

）。
