# 玄逵

玄逵，潤州江薴人，俗姓胡。童子出家，南往廣州，欲西渡求法。染疾歸，卒，年僅二十五六歲。詩一首。（《全唐詩》無玄逵詩，事跡據《大唐西域求法高僧傳》）

## 言離廣府還望桂林去留愴然自述贈懷云爾

標心之梵宇，運想入仙洲。

嬰痼乖同好，沉情阻若抽。

葉落乍難聚，情離不可收。

何日乘杯至，詳觀演法流。

（錄自《大正新修大藏經》第五十一冊唐釋義淨撰《大唐西域求法高僧傳》卷下）（按：《全唐詩》卷八○八收此詩於義淨名下，實誤。

詳詩意及義淨所敍前後文意，此詩應爲玄逵作，義淨不過鈔錄入）（傳而已。

義淨另有傷玄逵二詩，亦見同書，《全唐詩》已收入。

《古今禪藻集》卷一收三詩皆歸玄逵，亦誤。

又日本《天理圖書館善本叢書》影印古寫本《大唐西域求法高僧傳》，「玄逵」皆寫作「玄達」。

未詳孰是，謹錄出備考。

）。
