# 韋夏卿

韋夏卿，字雲客，京兆萬年人。大曆中，與弟正卿同舉賢良方正高等，授高陵主簿，累遷刑部員外郎，擢給事中，出爲常、蘇二州刺史。徐州節度使張建封辟爲徐泗行軍司馬，俄召爲吏部侍郎，進檢校工部尚書、東都留守，改太子少保。詩三首。

## 別張賈

束簡下高閣，買符驅短轅。

故人惜分袂，結念醉芳罇。

切切別思纏，蕭蕭征騎煩。

臨歸無限意，相視却忘言。

## 和丘員外題湛長史舊居

道勝物能齊，累輕身易退。

苟安一丘上，何必三山外。

雲霞長若綺，松石常如黛。

徒有昔王過，竟遺青史載。

詩因埜寺詠，酒向山椒酹。

異時逢爾知，茲辰駐余斾。

## 送顧況歸茅山

聖代爲遷客，虛皇作近臣。

法尊稱大洞，學淺忝初真。

鸞鳳文章麗，煙霞翰墨新。

羨君尋句曲，白鵠是三神。
