# 袁高

袁高，字公頤，恕己之孫，擢進士第。建中中，拜京畿觀察使，坐累，貶韶州刺史，復拜給事中。憲宗時，特贈禮部尚書。詩一首。

## 茶山詩

禹貢通遠俗，所圖在安人。

後王失其本，職吏不敢陳。

亦有姦佞者，因茲欲求伸。

動生千金費，日使萬姓貧。

我來顧渚源，得與茶事親。

甿輟耕農耒，采采實苦辛。

一夫旦當役，盡室皆同臻。

捫葛上欹壁，蓬頭入荒榛。

終朝不盈掬，手足皆鱗皴。

悲嗟遍空山，草木爲不春。

陰嶺芽未吐，使者牒已頻。

心爭造化功，走挺麋鹿均。

選納無晝夜，搗聲昏繼晨。

衆工何枯櫨，俯視彌傷神。

皇帝尚巡狩，東郊路多堙。

周迴遶天涯，所獻愈艱勤。

況減兵革困，重茲固疲民。

未知供御餘，誰合分此珍。

顧省忝邦守，又慙復因循。

茫茫滄海間，丹憤何由申。
