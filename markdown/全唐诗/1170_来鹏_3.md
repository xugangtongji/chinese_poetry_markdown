# 来鹏

来鹏，豫章人。家徐孺子亭边，林园自乐，师韩柳为文。咸通间，举进士不第。广明中，避地荆襄，中和间客死于维扬逆旅，主人收葬之。补诗一首。

## 水仙花（题拟） 一

瑶池来宴老金家，醉倒风流萼绿华。

白玉断笄金晕顶，幻成痴绝女儿花。

。

## 水仙花（题拟） 二

花盟平日不曾寒，六月曝根高处安。

待得秋残亲手种，万姬围绕雪中看。

（见《全芳备祖前集》卷二一「水仙花」门）。
